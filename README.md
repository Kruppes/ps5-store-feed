# ps5-store-feed

Static mirror of the public PS5 homebrew catalog Store API (schema 3,
https://github.com/blackbearreloaded/ps5-homebrew-catalog/blob/main/docs/api.md)
on GitHub Pages, for ProsperoStore's *Custom catalog* setting:

    https://kruppes.github.io/ps5-store-feed/api/v1/

Generated by `build-feed.py` from https://homebrew.page/api/v1/ (upstream
signature checked before mirroring). Only `icon`/`icon_small` are rewritten to
this host; `artifact_url`, `sha256`, `status` etc. are unchanged and point at
the developers' GitHub releases. `manifest.json` is re-hashed for the served
files and is **not signed** (no `manifest.sig`): turn signature verification
off for this catalog. `news.json`/`news.sig` are verbatim upstream copies.
